Cómo protegí una API con JWT

21 de octubre de 2026

En la API REST el registro y el login devuelven un token. Las rutas privadas solo responden si ese token es válido.

Las contraseñas no se guardan en texto plano: se hashean con bcrypt antes de entrar en la base de datos.
